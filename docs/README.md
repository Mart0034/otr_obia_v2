# OTR-finder demo site (GitHub Pages)

A static proof-of-concept page: interactive map, step-by-step explainer and result numbers, in English, German and
Spanish. No server, no build step.

## Publish
GitHub → *Settings* → *Pages* → *Build and deployment* → *Deploy from a branch* → branch `main`, folder `/docs`.
The page is then at `https://<user>.github.io/<repo>/`.

## Local preview
```bash
cd docs && python3 -m http.server 8000     # then open http://localhost:8000
```

## Data (`docs/data/`)
Generated by `scripts/export_site_data.py` from the reviewed candidate lists. **Public page, so locations are
generalised on purpose:** dumps and candidates are rounded to 0.01° cells (about 1 km) and merged per cell; no outlines,
no site IDs, no exact coordinates. Mine outlines are public data. Re-run the script after each review round:

```bash
python scripts/export_site_data.py --out docs/data --reviewed v4=... v5=... --candidates <open candidates.gpkg> \
    --known data/dump_labels.gpkg --mines data/mine_boundaries.gpkg
```
